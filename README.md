# 평택시장애인체육회 메인 시안

사이트는 순수 HTML, CSS, JavaScript로 구성되어 있습니다. 별도 설치 및 빌드 없이 `index.html`을 브라우저로 열 수 있습니다.

- `index.html` — 주요 메뉴, 배너, 공지, 신청현황, 활동 소식, 체육회 소개
- `styles.css` — 시안 스타일, 반응형 레이아웃과 키보드 포커스
- `site.js` — 전체 메뉴, 배너 전환, 게시판 탭과 접수 상태
- `assets/` — 체육회 공식 사진과 로고, Pretendard 글꼴 및 라이선스
- `.nojekyll` — 정적 파일을 그대로 게시하는 GitHub Pages 설정

게시판과 신청 정보는 시안 기준이며, 각 링크에서 공식 공고와 접수 페이지를 확인할 수 있습니다. 사진과 로고는 평택시장애인체육회 및 각 기관의 이미지를 사용했습니다. 지도는 Google Maps에서 제공됩니다.
