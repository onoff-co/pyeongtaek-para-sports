# 평택시장애인체육회 메인 시안

사이트는 HTML과 CSS로 구성된 정적 디자인 시안입니다. 별도 설치 및 빌드 없이 `index.html`을 브라우저로 열 수 있습니다.

- `index.html` — 주요 메뉴, 배너, 공지, 신청현황, 활동 소식, 체육회 소개
- `styles.css` — 시안 스타일, 반응형 레이아웃
- `assets/` — 체육회 공식 사진과 로고, ONF 워터마크, Pretendard 글꼴 및 라이선스
- `.nojekyll` — 정적 파일을 그대로 게시하는 GitHub Pages 설정

메뉴, 버튼, 게시판 탭과 배너는 시안의 화면을 보여주는 요소입니다. 게시판과 신청 정보는 시안에 표시된 내용을 사용합니다. 사진과 로고는 평택시장애인체육회 및 각 기관의 이미지를 사용했습니다. 지도는 Google Maps에서 제공됩니다.
